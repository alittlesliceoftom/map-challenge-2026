# Day 8 Utopia (car-free Waterloo Bridge to Covent Garden) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An animated 3D map of a car-free Waterloo Bridge, Strand and Covent Garden. Glowing trails when zoomed out, 3D walking people when zoomed in, pulsed bus convoys, an intro fly-through, then free exploration.

**Architecture:** Python (`days/08-utopia/`) fetches the corridor's streets and buildings from OSM, builds a walkable area plus a central lane, and generates synthetic trips (walkers, cyclists, buses) in metres (EPSG:27700). It then inlines those trips as JSON into a self-contained `map.html`. A hand-written JS block in the template runs the animation clock, deck.gl layers (TripsLayer / ScenegraphLayer / SimpleMeshLayer) over a MapLibre 3D basemap, layer switching by zoom, and the camera tour.

**Tech Stack:** Python 3.11+, osmnx, geopandas, shapely, numpy, pytest. Browser side: deck.gl and MapLibre GL JS from a CDN, OpenFreeMap "liberty" style (3D buildings), and the Khronos CesiumMan glTF.

**Spec:** `docs/superpowers/specs/2026-11-08-utopia-design.md`

## Global Constraints

- Work on a branch `day-08-utopia` in `~/projects/map-challenge-2026` (it's on `main` now). Never push. Tom merges.
- `build.py` copies only `map.html` into the site, so `map.html` must be self-contained: trips inlined as JSON. External assets come only from CDNs (JS libs, basemap style/tiles, the glTF URL).
- CDN script URLs pin exact versions (e.g. `maplibre-gl@4.7.1`, `deck.gl@9.1.x` with a concrete patch). Never `@latest` or a bare major. Verify each URL returns 200 before committing.
- Basemap is free and key-less: `https://tiles.openfreemap.org/styles/liberty`.
- New Python deps (`osmnx`, `shapely`, `numpy`) go in `requirements.txt`, never `requirements-site.txt`.
- No cars anywhere. Buses appear only in pulses: about 180 s with no buses, then a ~30 s convoy. The central lane is a single lane with traffic lights, so each pulse runs one way and the next runs the other. `LOOP_S = 420`, `PULSES = [(180, 210, +1), (390, 420, -1)]` as (start s, end s, direction along route).
- Walkers move in both directions and zigzag across the full former carriageway. They are never inside buildings or the river, and loosely keep out of the central lane, which buses and cyclists use.
- Trails below zoom 17; 3D figures at zoom 17 and above. Both come from the same trip data.
- If the glTF fails to load, trails show at every zoom. The page must never break.
- `map.html` stays under 5 MB. It should be smooth on a laptop. On phones, cap agents and allow trails-only.
- The corridor starts at the Waterloo station forecourt / Waterloo Road (no station interior) and ends in the Covent Garden piazza.
- Agent volumes are illustrative and labelled as such. Notes state the bus assumption: other routes divert via Blackfriars and Westminster, and the convoy is what's left.
- No emojis in content files.

### Task 2: Walker and cyclist trips

**Files:**
- Create: `days/08-utopia/agents.py`
- Test: `tests/test_day08_utopia.py`

**Interfaces:**
- Consumes: `Corridor`, `CRS` (Task 1)
- Produces:
  - `LOOP_S = 420.0`, `PULSES = [(180.0, 210.0, 1), (390.0, 420.0, -1)]`
  - `@dataclass Trip: kind: Literal["walk", "bike", "bus"]; path: list[tuple[float, float]]; timestamps: list[float]` (metres in `CRS`, seconds)
  - `walker_trips(c: Corridor, n: int, rng: np.random.Generator) -> list[Trip]`
  - `cyclist_trips(c: Corridor, n: int, rng: np.random.Generator) -> list[Trip]`

The walker algorithm is a choice the tests don't determine. Pick a route (weighted by length) and a random direction, and a random entry/exit fraction along it so not everyone walks the full length. Place a waypoint about every 20 m along it. Offset each waypoint laterally by a uniform draw across the full walkable width at that point (measure it by casting a perpendicular and clipping to `c.walkable`), excluding the lane band. Smooth with 2 Chaikin passes. Drop or nudge any point outside `c.walkable`. Speed is drawn per walker from 1.1 to 1.5 m/s, and the start time is uniform in [0, LOOP_S). Cyclists ride inside `c.lane` (lateral offset within ±1.5 m, no Chaikin wander) at 4 to 6 m/s. Their timestamps are cumulative distance divided by speed.

```python
def test_walkers_inside_walkable(corridor): every point of 200 walker trips within corridor.walkable.buffer(0.5)
def test_walkers_zigzag(corridor): std of lateral offset across all points > 3.0 m; each trip >= 60 m long changes lateral side (sign of offset) at least once
def test_walkers_mostly_avoid_lane(corridor): fraction of walker points inside lane < 0.10
def test_walkers_both_directions(corridor): 0.35 < share moving +x < 0.65
def test_walker_speeds(corridor): segment-average speed per trip in [1.0, 1.7]; timestamps strictly increasing
def test_cyclists_in_lane_and_fast(corridor): all points in lane.buffer(0.5); speeds in [3.5, 7.0]
```

### Task 3: Bus pulses, loop wrap, JSON export

**Files:**
- Modify: `days/08-utopia/agents.py`
- Test: `tests/test_day08_utopia.py`

**Interfaces:**
- Produces:
  - `bus_trips(c: Corridor, n_per_pulse: int, rng: np.random.Generator) -> list[Trip]`. Buses run along the lane centreline of the `c.lane_routes` stretches at 5 to 7 m/s. Each pulse in `PULSES` sends all its buses in that pulse's direction only, so the single lane never has opposing buses. Starts are staggered about 4 s apart inside the pulse. Any bus still moving at the pulse end is clipped so it exits by then. Shorten the route rather than run over.
  - Add JS traffic lights at each end of the bridge (Task 5): green for the direction of the active pulse, red otherwise.
  - `wrap_loop(trips: list[Trip], loop_s: float = LOOP_S) -> list[Trip]`. It returns the trips plus, for each trip with `timestamps[-1] > loop_s`, a copy shifted by `-loop_s`.
  - `to_deck_json(trips: list[Trip], crs: str = CRS) -> list[dict]`. It returns `{"k": "w"|"b"|"u", "p": [[lon, lat], ...] (6 dp), "t": [s, ...] (1 dp)}` with short keys to keep the file small (`u` = bus).
